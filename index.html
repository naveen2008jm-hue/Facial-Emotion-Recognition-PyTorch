    def __init__(self, num_classes=7, in_channels=1):
        super().__init__()
        self.block1 = ConvBlock(in_channels, 32, dropout_p=0.20)
        self.block2 = ConvBlock(32, 64, dropout_p=0.25)
        self.block3 = ConvBlock(64, 128, dropout_p=0.25)
        self.block4 = ConvBlock(128, 256, dropout_p=0.30)
        
        self.classifier = nn.Sequential(

            nn.ELU(inplace=True),
            nn.Dropout(p=0.4),

AI Coursework Viva & Presentation Q&A
1. Why use Exponential Linear Units (ELU) over standard ReLU?

ELU allows activations to have smooth, non-zero negative outputs $(e^x - 1)$ when $x < 0$. This brings the mean unit activation closer to zero, accelerating gradient descent convergence and preventing the Dying ReLU problem where inactive neurons permanently output 0.

2. How is the severe class imbalance in FER-2013 addressed?

In FER-2013, the Disgust class contains only ~547 samples while Happy has over 8,989 samples (~18x difference). We compute inverse class frequency weights:
weight[c] = Total_Samples / (Num_Classes * Count[c])
and pass these weights into nn.CrossEntropyLoss(weight=weights) so minority class errors are penalised proportionally higher during backpropagation.

3. What data augmentations are used and why?

We use RandomHorizontalFlip(p=0.5), RandomRotation(±10°), and RandomAffine(translation=±6%). Since faces remain emotionally valid when mirrored or slightly rotated, this effectively expands the training space and prevents overfitting to head poses.

4. How does Batch Normalization prevent overfitting and improve speed?

Batch Normalization normalizes the mini-batch mean and variance before non-linear activations. This reduces internal covariate shift, enables higher learning rates, acts as a regularizer, and reduces sensitivity to parameter initialization.
